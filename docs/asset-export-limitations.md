# GLB export checks and remaining limits

## Root bone display length

glTF stores joint transforms, not bone tails. Blender 5.2.2 chooses a root's
display length from its translation when all direct child joints coincide with
it. This produced a length of 7.71 for `FIGHT_Spectre_4.gao` in `FF005520`
(root `9E006A5E`), and 5.13 for militaire, depending on scene placement.

For coincident root children, export now adds one unweighted `display tip`
joint, marked `displayOnly` in node extras. It provides a 0.05 local endpoint,
has a consistent inverse bind, and does not change source joints, vertex weights
or animation channels. Roots with an existing offset child keep their layout.
This corrects the placement-dependent display artifact; it does not shorten
genuine source bones or establish that every actor's rig has been verified.

## Inverse alpha masks

Jade's inverse alpha test discards `alpha >= reference`; glTF MASK retains
`alpha >= cutoff`. The old export incorrectly used the same cutoff direction.
Spectre's tail also has a constant alpha override below its reference, so the
ordinary mask discarded its otherwise visible surface.

For opaque inverse-test layers with constant alpha, export bakes the source
comparison and override into PNG alpha, uses cutoff 0.5 and factor alpha 1,
and marks the material `bakedInverseAlphaTest`. RGB and UVs stay unchanged.
All texel visibility decisions match the source comparison. Filtered mask edges
remain approximate; variable vertex/instance alpha and blended inverse tests
are not reconstructed by this bake. Unsupported blends still report warnings.
Multi-pass effects continue to export the primary color pass unless a supported
layer bake is available; complete native shader parity is not claimed.

## Verification

Military HD eyes (`A90052FD` / `A90052FE`) have two color passes: a bone-projected
eye followed by a stored-UV face atlas using source-alpha blending. Export used
to retain only the eye pass, losing the face/eyelid overlay and making eyes look
too large. The two passes now bake to a triangle atlas with independent UVs and
the overlay's constant alpha factor. The same bounded bake applies to equivalent
two-pass materials; unsupported color modes and view-dependent mappings are
excluded. As with Sally's three-pass bake, eye projection is frozen at the
selected pose, not reconstructed as an animated shader.

Military armor materials `16002AE6` / `16002AE7` start with a view-dependent
environment pass and add stored-UV detail color (`62001BD5` / `62001BD4`). Export
now selects that detail as the opaque base color instead of placing the reflection
texture in its UV map. The second pass's alpha controls reflection contribution,
so it is not exported as surface opacity. This is a detail-color approximation;
the original camera-dependent reflection is omitted and reported as a warning.

`blender_military_face_check.py <GLB> <reference.json> <report.json> [render.png]`
checks the imported neutral head against source-evaluated skin vertices, both
baked eye materials and optional rendered output. On the original military HD
head, all exported morph weights are zero; 801 imported UV-split vertices match
the 476-vertex source reference within 0.0000021 world units. No extra geometric
face/eye scaling was observed for that tested pose. Reference and source-material
reports are generated by `MilitaryMaterialChecks` in the normal verification run.

`ExportVerification --actor-audit <BF> FIGHT_Spectre_4.gao` finds and exports
the first matching parsed actor, checks skinning against the editor at two
animation times, and compares all three inverse masks against source texels.
The archive uses `_4`, rather than `_04`, in this instance's name.

`blender_import_check.py <GLB> <report.json> [max-bone-length] [max-root-length]`
checks imported mesh bounds and actual Blender bone lengths. Spectre's root
changed from 7.71 to 0.05 without changing mesh bounds beyond float tolerance;
militaire and Peyj imports also passed the root-length limit of 0.1.
